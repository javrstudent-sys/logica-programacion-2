# Práctica: Conversor de Temperatura (Lógica de Programación 2)

Programa desarrollado en **JavaScript** que solicita al usuario una temperatura en grados Celsius, valida que el dato ingresado sea estrictamente numérico, realiza las conversiones correspondientes a grados **Fahrenheit** y **Kelvin**, y muestra los resultados.

## 🛠️ Tecnologías Usadas

* HTML5
* CSS3
* Bootstrap 5
* JavaScript (ES6)

## 📐 Fórmulas de Conversión

* **Fahrenheit:** $(C \times \frac{9}{5}) + 32$
* **Kelvin:** $C + 273.15$

## 🧪 Casos de Prueba Verificados

1. **Entrada:** `45`
   * **Grados Kelvin:** `318.15`
   * **Grados Fahrenheit:** `113`
2. **Entrada:** `14`
   * **Grados Kelvin:** `287.15`
   * **Grados Fahrenheit:** `57.2`
